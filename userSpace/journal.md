**Пользовательский режим**

**Обертка (sys/ioctl.c)**

ioctl - позволяет обращаться к девайсам устройств через системмный вызов, дальше ядро определяет к какому типу относятся событие и обрабатывает его
Реализовано:

uart - в зависимости от типа операции выполняется: инициальзация (UART_SET_MODE), запись (UART_WRITE), чтение (UART_READ)

gpio - указывается его пин, в соответсвии с документации,
в зависимости от типа операции выполнятется: инициальзация, запись, чтение, также доп надо указать режим работы как вход или выход
и установить уровень напряжения. Для этих занчений существует стурктура GpioArg
в структуре есть:
.pin - определяет номер пина
.mode - задает настройку пина либо (union) .value - уровень напряжения

sdmmc - в зависимости от типа операции выполнятется: инициальзация, запись, чтение. В чтении и записи надо указывать 
тип передачи/чтения (.type), индекс (.index), размер буфера (.size) и сам буфер (.buf). Передается через структуру SDMMCArg

i2c - реализовано через структуру I2cArg 
инициализация (I2C_SET_MODE) - работаем с каким девайсом (I2C1,2,3,4), mode (MASTER или SLAVE), addr (адрес устройства, можем быть и мы устройством). ВАЖНО, чтобы поменять адрес чтения/записи, надо производить I2C_SET_MODE;
запись (I2C_WRITE) - работаем с каким девайсом (I2C1,2,3,4), массив значений (что хотим записать), длина массива занчений;
чтение (I2C_READ) - работаем с каким девайсом (I2C1,2,3,4), массив для значений (читаются данные с датчика), длина массива для занчений;
чтение регистра (I2C_READ_REG) работаем с каким девайсом (I2C1,2,3,4), какой регистр датчика хотим прочитать, массив для значений (читаются данные с датчика), длина массива для занчений
